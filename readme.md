# 💼 Aplikasi Kasir

Aplikasi kasir berbasis web sederhana yang membantu pemilik toko dalam mengelola transaksi penjualan, produk, dan laporan keuangan.

## ✨ Fitur Utama

- 🛒 Manajemen produk (tambah, edit, hapus)
- 📦 Stok barang
- 💰 Transaksi penjualan
- 📊 Laporan penjualan harian dan bulanan
- 👥 Login multi-user (admin & pemilik toko)
- 🔒 Reset password melalui email


## ⚙️ Teknologi yang Digunakan

- PHP (native)
- MySQL
- HTML, CSS, JavaScript
- Bootstrap (UI Framework)

## 🚀 Instalasi Lokal

Ikuti langkah berikut untuk menjalankan proyek ini secara lokal:

```bash

git clone https://github.com/RahmatullahWiryaAdikusuma/Kasir.git

# Masuk ke direktori

# Import file kasir.sql dari folder /database
```
